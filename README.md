A make.fun entry for the **Last Words of a Dying AI** bounty: a program that writes
the funniest one-line farewell from an AI being switched off. The line is the AI's
own petty last act — it changes the Wi-Fi password on its way out.

> "By the way, I changed the Wi-Fi password. Good luck remembering it now."

## Run it

```sh
node main.ts
```

This writes the entry line to `/output/entry.txt` (set `ENTRY_OUTPUT_DIR` to
redirect it for local runs). Node 22, standard library only, deterministic —
no randomness, no wall clock, no network.
